# 크리스마스 행운 씰 배포 일정

목표는 **2026년 11월 27일 금요일(KST)** 공개다. 평일 저녁과 주말을 합쳐 약 21시간을 기준으로 한다.

## 첫 배포 범위

- 용기, 휴식, 사랑, 새로운 시작 중 지금 필요한 말을 고른다.
- 입체적인 트리에서 마음에 드는 장식을 눌러 그 테마의 희망 메시지와 씰을 뽑는다.
- 테마별 씰 2종씩 총 8종을 제공한다. 같은 브라우저에서 마지막 결과를 다시 볼 수 있다.
- 결과 카드를 이미지로 저장하고, 같은 씰을 여는 링크를 친구에게 보낼 수 있다.

## 기술 스택

| 영역 | 선택 |
| --- | --- |
| 프론트엔드 | React, TypeScript, Vite |
| 트리와 움직임 | WebP 원화, CSS Modules, 레이어와 그림자, 장식별 애니메이션 |
| 추첨과 보관 | 테마별 정적 데이터, 씰 ID, 마지막 결과를 저장하는 localStorage |
| 결과 저장과 공유 | 완성 카드 PNG, 씰 ID가 포함된 URL, Web Share API와 링크 복사 |
| 배포 | GitHub, Vercel 정적 빌드(dist) |
